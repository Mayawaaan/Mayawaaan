## 👨‍💻 Who am I?

I am a passionate **Software Engineer** from India 🇮🇳 with a degree in Computer Science and Engineering. I specialize in blurring the line between software engineering and digital art through **Interactive 3D Web Development** while backing it up with robust, scalable **Cloud and Full-Stack** architectures.

- 🔭 **Currently Building:** Advanced React patterns, open-source tools, and immersive 3D experiences.
- 🎨 **Creative Tech:** I love rendering high-performance 3D graphics on the web using **Three.js, React Three Fiber, and GLSL**. (Check out my Audi R8 3D project on my portfolio!).
- ☁️ **Cloud Native:** Experienced in **Google Cloud (GCP)**, deploying to Kubernetes, and managing modern cloud infrastructure.
- 🤖 **Data & Machine Learning:** Hands-on experience with **Python, LSTM neural networks**, and integrating ML APIs into web apps.
- 🤝 **Collaboration:** Always open to collaborating on Open Source Web Projects, Data Science initiatives, or hackathons.
- 💬 **Ask me about:** `Three.js`, `MERN Stack`, `Java`, `Angular`, or navigating Google Cloud.
