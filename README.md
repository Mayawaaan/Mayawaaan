## 👨‍💻 Who am I?

I am a **Software Engineer** specializing in bridging the gap between highly interactive digital art and data-driven applications. My core expertise lies in **3D Web Development** and **Data Science**, backed by a robust foundation in full-stack engineering.

- 🐍 **Core Logic & DSA:** Python is my primary language for problem-solving, data structures, and algorithms.
- 🎨 **3D Web Development:** Building immersive, high-performance web experiences using **Three.js, WebGL, and Blender**, brought to life with **GSAP** and **Framer**.
- 📊 **Data Science:** Analyzing and visualizing complex datasets using the **Python ecosystem (NumPy, Pandas, Statistics)**.
- ⚙️ **Full-Stack (MERN):** Developing scalable web applications with **MongoDB, Express.js, React, and Node.js**.
- 💬 **Ask me about:** 3D WebGL implementations, MERN architecture, or Python data modeling.
